# คู่มือเก็บรูปยาสำหรับเทรนโมเดล

ข้อมูลคือสิ่งที่กำหนดคุณภาพโมเดลมากที่สุด

## เป้าหมายขั้นต่ำ ต่อยา 1 ชนิด
- 150-300 รูปสำหรับเทรน + **50 รูปแยกไว้ทดสอบ (ห้ามเอาไปเทรน)**
- ถ่ายยา "คนละกล่อง/คนละแผง" ถ้าหาได้ ไม่ใช่กล่องเดียวถ่ายซ้ำ ๆ (ไม่งั้นโมเดลจำกล่องนั้น ไม่ได้จำยา)

## ความหลากหลายที่ต้องมี
- มุม: ตรง เอียง หมุน กลับด้าน ระยะใกล้/ไกล
- แสง: ไฟห้อง แสงแดด มืด ๆ แฟลช
- พื้นหลัง: โต๊ะไม้ โต๊ะขาว ผ้า มือถือถือ ในถุง
- คุณภาพ: เบลอเล็กน้อย (เหมือนที่ผู้สูงอายุถ่ายจริง) ใช้กล้องมือถือหลายรุ่น
- ถ่ายผ่านแอป LINE จริง ๆ บางส่วน (LINE บีบอัดรูป)

## คลาส "ไม่ใช่ยา / ไม่รู้จัก" (สำคัญมาก)
- 300+ รูป: ยาชนิดอื่นที่ไม่อยู่ในระบบ, กล่องผลิตภัณฑ์อื่น, ขวดน้ำ, มือเปล่า, โต๊ะ, หน้าคน, ภาพเบลอมืด
- ตั้งชื่อโฟลเดอร์ `not_a_drug`

## โครงสร้างโฟลเดอร์
```
dataset/
  train/  ซาร่า/  ยาธาตุน้ำขาวกระต่ายบิน/  ไทลินอล/  not_a_drug/
  test/   (โครงสร้างเดียวกัน คนละรูปกับ train)
```
ชื่อโฟลเดอร์ต้องตรงกับ `models/labels.txt` (ตอนเทรนใหม่เราจะเปลี่ยนเป็นรหัส ASCII)

## ข้อควรระวัง
- รูปที่มีคนอื่น/ข้อมูลส่วนตัวติดมา ต้องไม่นำมาใช้ ถ้าจะเก็บรูปจากผู้ใช้จริง ต้องขอความยินยอมก่อน
